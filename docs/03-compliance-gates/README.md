# Security Scanning

This directory documents the security scanning tools used in the Zero Downtime CI/CD Pipeline.

## Security Checks

* **Secret Scanning:** Checks for exposed secrets.
* **SAST:** Analyzes source code for potential security issues.
* **Dependency Scan:** Checks dependencies for known vulnerabilities.
* **Docker Image Scan:** Scans the Docker image for vulnerabilities.
* **OWASP ZAP DAST:** Tests the running application for potential web security issues.

## Objective

To identify security risks early in the CI/CD pipeline and improve application security before production deployment.
