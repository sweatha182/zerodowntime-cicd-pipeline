# Observability Documentation

This directory documents monitoring, logging, and troubleshooting practices for the Zero Downtime CI/CD Pipeline.

## Objectives

* Monitor CI/CD workflow execution.
* Review application and deployment logs.
* Identify failed pipeline stages.
* Track application health after deployment.
* Support troubleshooting and recovery.

## Monitoring and Logging

* Review GitHub Actions logs to identify workflow failures.
* Check application health after deployment.
* Investigate errors before attempting a new deployment.
* Record relevant findings to support troubleshooting.
